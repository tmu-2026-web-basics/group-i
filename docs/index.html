いつもの道を、少し違う目線で。

普段、スマホばかり見ながら歩いていませんか？
少しだけ視線を上げてみると、いつもの道にも意外な発見があります。
そのひとつが「街灯」。
よく見ると、丸いものや細長いもの、レトロなものなど、
一つひとつ違った表情をしています。
このサイトでは、そんな個性あふれる街灯たちを集めました。
今日は少しだけ、上を向いて歩いてみましょう！

ここまでご覧いただき、ありがとうございました。
街灯には、それぞれ違った形や雰囲気があり、
街の景色をさりげなく彩っています。

このサイトをきっかけに、歩くときに少しだけ
上を向く習慣が生まれたら嬉しいです。
